# SQL Sales Analysis Project



## Project Overview



This is my first SQL project built using MySQL.



The project demonstrates how SQL can be used to create a relational database, store sales data, connect multiple tables, and perform basic business analysis.



## Tools Used



- MySQL

- MySQL Workbench

- GitHub



## Database Structure



The database contains three tables:



### Customers



Stores customer information:



- Customer ID

- Customer Name

- Country

- Customer Type



### Products



Stores product information:



- Product ID

- Product Name

- Category

- Price



### Sales



Stores sales transaction information:



- Sale ID

- Customer ID

- Product ID

- Sale Date

- Quantity



## SQL Concepts Used



- CREATE DATABASE

\- CREATE TABLE

\- INSERT

\- SELECT

\- JOIN

\- GROUP BY

\- ORDER BY

\- SUM

\- COUNT

\- LIMIT

\- Aggregate Functions

\- Foreign Keys



## Business Questions



This project analyzes:



1\. Total number of customers

2\. Total number of sales

3\. Total quantity sold

4\. Total revenue

5\. Revenue by product

6\. Revenue by country

7\. Revenue by customer type

8\. Monthly revenue

9\. Top 5 customers
